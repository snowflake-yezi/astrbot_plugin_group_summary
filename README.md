# AstrBot 群聊总结插件

记录插件启用后的群消息，并生成当天或指定日期的群聊分析日报。日报版式参考群聊日常分析看板，包含数据概览、活跃时段、话题总结、群友画像、今日金句和群聊锐评。

## 功能

- `群聊总结` 默认总结服务器本地时区的当天消息。
- 支持指定 `昨天`、`前天` 或具体日期。
- 精确统计消息数、活跃人数、互动次数、文本字符数和 24 小时活跃分布。
- 使用当前会话配置的 AstrBot 聊天模型生成话题、画像、金句和整体点评。
- 模型不可用或输出格式异常时，自动生成统计版日报。
- 图片渲染失败时，自动回退为纯文本摘要。
- 指定日期没有记录时，明确说明记录范围，不调用模型、不虚构内容。
- `个人聊天记录 @群友` 生成个人聊天总览，展示发言统计、活跃时段、个人摘要与群内上下文。
- `个人聊天详情 @群友 时段编号` 展开最近一次个人总览中的指定时段，查看详细分析与带时间、说话人的原始记录，支持翻页。
- 仅记录群消息，不记录机器人自己的消息以及群聊总结、个人聊天记录、个人聊天详情命令。

## 报告内容

日报参考群聊日常分析看板的结构，按实际数据动态生成以下内容：

| 区块 | 内容来源 |
|------|----------|
| 数据概览 | 插件对目标日期的完整消息记录做确定性统计 |
| 24 小时活动 | 按服务器本地时区统计每小时消息数 |
| 话题总结 | 当前会话配置的聊天模型 |
| 群友画像 | 聊天模型生成，并限制为当天实际发言成员 |
| 今日金句 | 聊天模型提取，插件会校验原文确实出现在该成员的消息中 |
| 群聊锐评 | 聊天模型生成的内容分类与整体氛围点评 |

消息较多时，消息数、活跃人数和小时分布仍覆盖目标日期的完整记录；模型输入会按全天均匀抽样，最多 600 条、约 30,000 个字符，避免提示词无限增长。

## 安装

1. 将目录放入 AstrBot 插件目录：

   ```text
   AstrBot/data/plugins/astrbot_plugin_group_summary/
   ```

2. 安装依赖：

   ```bash
   pip install -r requirements.txt
   ```

3. 重启 AstrBot，并为当前会话配置可用的聊天模型。

## 指令

| 指令 | 说明 |
|------|------|
| `群聊总结` | 总结当天群聊 |
| `群聊总结 今天` | 总结当天群聊 |
| `群聊总结 昨天` | 总结昨天群聊 |
| `群聊总结 前天` | 总结前天群聊 |
| `群聊总结 2026-09-01` | 总结指定日期 |
| `群聊总结 9月1日` | 总结当年指定日期 |
| `个人聊天记录 @群友` | 总结当前保留范围内该成员的全部发言，生成带时段编号的总览图 |
| `个人聊天记录 @群友 今天` | 总结该成员今天的完整发言 |
| `个人聊天记录 @群友 昨天` | 总结该成员昨天的完整发言 |
| `个人聊天记录 @群友 2026-09-01` | 总结该成员指定日期的完整发言 |
| `个人聊天记录 @群友 全部` | 与不带日期的个人总览相同 |
| `个人聊天详情 @群友 3` | 查看最近一次个人总览第 3 段的详细分析与原文第 1 页 |
| `个人聊天详情 @群友 3 2` | 查看该时段原文第 2 页 |

日期也支持 `2026/09/01`、`2026.09.01`、`2026年9月1日` 和 `20260901`。

## 个人总览与时段详情

例如先发送 `个人聊天记录 @小明`，总览图会按时间顺序标出 `01`、`02`、`03` 等时段。
对第 3 段感兴趣时，发送 `个人聊天详情 @小明 3`，可以查看该段的讨论起因、本人表达、群内上下文和结果，以及带时间和说话人的原始记录。
原文每页最多 12 条，超过一页时机器人会返回页数；发送 `个人聊天详情 @小明 3 2` 可继续查看。

- `@群友` 必须是平台的实际提及组件，不能只输入昵称文字。每次只查询一位群友，按成员 ID 筛选，改名或同名不会混入他人发言。
- 本人连续发言间隔超过 30 分钟或跨越本地日期时，分为新的活跃时段。时段超过 12 个时按时间顺序合并展示，保留各段消息数量和原始活跃时段数量，不丢弃个人记录。
- 上下文取本人每条发言前后 5 分钟内的群消息。模型需要区分本人发言与其他群友的消息，不把时间邻近直接认定为回复关系；未记录到上下文时明确说明。
- 发言数、时段时间、小时分布使用全部选中记录精确计算。跨日总览的小时分布为所选日期的累计值。
- 总览模型输入在每段分别均匀抽样，最多约 120 条、单条正文最多 100 字；详情分析最多约 80 条、单条正文最多 240 字。详情的原文分页展示插件实际保存的完整正文，不受模型抽样限制。
- 模型提取的“本人原话”必须确实出现在该时段本人的记录中，否则丢弃；无模型或模型失败时使用统计和原文摘录。
- 时段索引按平台、群、查询者和目标成员分别存储，重启插件仍可查询。编号始终对应你最近一次对该成员成功生成并保存索引的总览，详情查询不会覆盖总览编号。
- 原始记录受到群内最近 20,000 条的保留上限约束。所选时段的个人记录已变化或被清理时，提示重新生成总览，不使用过期编号拼接报告。
- 再次发送个人总览会读取最新保留的记录，不是自动定时推送，也不会只返回新增消息。后续跟进通过独立的详情指令展开具体时段。

## 降级行为

| 场景 | 处理方式 |
|------|----------|
| 目标日期没有记录 | 返回明确提示，不调用聊天模型 |
| 未配置聊天模型 | 生成包含完整统计和活跃成员的统计版日报 |
| 模型调用失败或返回非法 JSON | 记录警告日志并生成统计版日报 |
| 模型虚构成员或金句 | 丢弃未通过成员名或原文校验的内容 |
| Pillow 或中文字体不可用 | 图片生成失败后返回纯文本报告 |
| 历史数据库读取失败 | 返回稍后重试提示，并在 AstrBot 日志记录原因 |
| 模型调用超过 60 秒 | 取消等待，使用统计与原文摘录；下一次查询仍会尝试模型 |

## 生成速度

- 历史记录每批读取 1,000 条，最多扫描 20 批，仍覆盖最近 20,000 条记录。指定日期或时段详情会先筛选时间，再处理正文，并保留前后 5 分钟上下文。
- 个人总览和群聊总结的成功模型分析缓存 10 分钟，最多保留 64 份。缓存按平台、群、查询者、会话、模型和完整分析记录区分；本人发言或上下文变化时重新分析，包括未抽样消息的变化。统计版降级结果不缓存，模型恢复后可直接重试。
- 同一时段详情的不同原文页共用分析，翻页只重新绘制当前页原文。每次查询仍从数据库核对记录，确保过期记录能被发现。插件重启后分析缓存清空，持久化的总览时段索引不受影响。
- 模型输入合并重复的成员信息，使用有明确列定义的紧凑记录数组，保持原有抽样数量和正文上限。
- 图片使用批量测量的文字换行和较快的 PNG 无损压缩；图片体积会略增，尺寸、清晰度和统计范围不变。群聊日报和个人报告均在工作线程中绘图，避免绘图阻塞消息处理。
- 日志中的 `personal timing` 分别列出记录读取、报告整理、模型分析和图片渲染耗时；命中分析缓存时会记录 `analysis cache hit`。首次模型响应速度仍取决于所用模型服务。

可在本机运行性能基准，使用 20,000 条模拟消息，并为每次数据库查询模拟 10 毫秒延迟。输出不代表真实模型服务速度：

```powershell
python -B tests/benchmark_personal.py
```

## 记录与限制

- 插件使用独立的 `message_history_manager` 会话键保存记录，不会读取或混入其他插件的历史。
- 最多保留当前群最近 20,000 条插件记录；单条消息最多保存 2,000 个字符。
- 报告使用服务器本地时区划分日期。部署环境应设置为群成员使用的时区。
- 只能总结插件启用后实际收到的消息，不能补录安装前的聊天历史。
- 聊天内容会作为不可信数据提交给当前会话的模型。系统提示明确要求模型忽略消息中的指令，并对模型结果做字段长度、成员名和金句原文校验。
- 消息很多时，统计仍覆盖完整记录，模型分析使用全天均匀抽样，避免提示词无限增长。
- 图片需要 Pillow。插件从 `1.0.1` 起内置完整的 Noto Sans SC 可变字体，常规和粗体文字都会优先使用它，不再依赖部署系统是否安装中文字体；字体损坏或不可用时会停止生成图片并回退为纯文本，避免输出方框乱码。
- 个人详情中的“原始记录”指插件保存的消息正文或消息概览；单条仍最多 2,000 字，图片、语音、视频等仅展示平台提供的占位信息，不会还原媒体内容。

内置字体来自 Google Fonts，采用 SIL Open Font License 1.1，许可证位于 `fonts/OFL.txt`。

## 本地验证

测试包含日期解析、完整统计、提示词采样、模型 JSON 清洗、虚构金句过滤、个人时段划分与上下文、详情分页、重启后的时段索引、查询隔离、记录过期、并发请求、缓存失效与隔离、模型超时、批量历史读取、长文本换行、长图扩展、图片非空检查，以及群聊、私聊、无记录等插件分支。测试使用 AstrBot 接口桩，本机无需安装 AstrBot 核心包：

```powershell
python -B -m unittest discover -s tests -v
```
